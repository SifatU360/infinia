# Infinia AI Assistant

![Infinia Logo](src/assets/infinia.png)

## 🌟 Overview

Infinia is an AI-powered assistant that helps users with various tasks through natural language interactions. Built with React and Vite, it provides a modern, responsive interface for seamless AI communication.

## ✨ Features

- 💬 Natural language conversation
- 🎨 Clean and intuitive user interface
- ⚡ Real-time responses
- 🔍 Smart context understanding
- 🎯 Customizable AI interactions
- 🔒 Privacy-focused design

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm 

### Installation

```bash
# Clone the repository
git clone https://github.com/SifatU360/infinia.git

# Navigate to project directory
cd infinia

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Technologies Used

- React 18
- Vite
- Context API
- Modern CSS
- AI Integration

## 📖 Usage

1. Start the application
2. Type your prompt in the input field
3. Use the microphone or gallery icons for different input methods
4. Click the send button to get AI responses

## 🎯 Example Prompts

- "Suggest beautiful places to see on an upcoming road trip"
- "Improve the readability of code"
- "Summarize urban planning concepts"
- "Brainstorm team bonding activities"
